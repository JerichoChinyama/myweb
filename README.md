## Project Overview
This website is an interactive student portfolio developed for ICT251 Activity 3. It expands upon Activity 2 by introducing modern responsive CSS styling and dynamic JavaScript capabilities.

---

## Included JavaScript Features

1. **Form Validation & Local Summary Preview (Compulsory):**
   - Validates Name, Email, and Message fields on submit.
   - Rejects whitespace-only entries and malformed emails.
   - Prevents page reload using `event.preventDefault()` and presents a local submission preview summary.

2. **Light / Dark Theme Switcher:**
   - Toggles the document appearance between light and dark themes using custom CSS class properties.

3. **Expandable Content / FAQ Section:**
   - Shows or hides detailed project descriptions via interactive toggle buttons.

4. **Study Hours Calculator:**
   - Calculates weekly study hours based on daily inputs and displays validated output.

---

## How to Test
1. Open `index.html` locally using Live Server or visit the live Render URL.
2. Scroll to the **Contact** section, enter test inputs, and submit the form to view validation and local feedback.
3. Click the **Theme Toggle** button in the header to switch between light and dark visual themes.
4. Expand and collapse project details using the toggle buttons in the **Projects** section.
5. Enter values into the **Study Hours Calculator** to compute weekly study targets.
